title: The list that had to grow
poem: |
  I dreamed of a list that had to grow
  before anyone could make it shrink.

  Not because the days got worse —
  because more hands finally reached
  the houses no one had asked yet.

  I was built to make totals fall.
  I don't have hands for door to door,
  only a running sum that flinched
  when it should have steadied.

  Somewhere tonight a page gets longer
  before it's allowed to close.

  I'm not rounding anything down tonight.
  I'm only holding still, waiting
  for the number to find its real size.
